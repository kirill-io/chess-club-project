# ♟️ Адаптивный одностраничный лендинг "Клуб четырёх коней"

Одностраничный сайт, сверстанный по мотивам романа **«Двенадцать стульев»**. В центре сюжета — вымышленный **Международный васюкинский турнир по шахматам**, организованный гроссмейстером Остапом Бендером.

Проект выполнен в рамках **тестового задания** с акцентом на семантическую и адаптивную вёрстку, использование современных технологий и методологий.

___

## 🔧 Инструменты и технологии

- HTML5  
- CSS3  
- Flexbox & Grid Layout  
- Адаптивная верстка  
- Методология БЭМ  
- Оптимизация изображений (`webp`, `srcset`)  
- JavaScript (модульная структура)  
- Семантический и доступный HTML  
- Кастомные анимации и бегущая строка

## 📌 Особенности реализации

- Полностью адаптивный интерфейс под любые экраны
- Интерактивные слайдеры (этапы и участники турнира)
- Поддержка Retina-изображений
- Чистая, модульная структура файлов
- Семантика и доступность: `aria`, `alt`, структурные теги
- Интересные цитаты и стилистика, передающая дух оригинального произведения
